ساخت APK بدون نصب Android Studio

این بسته پروژه را در GitHub می‌سازد و فایل APK را به‌صورت Artifact تحویل می‌دهد.

مراحل:
1) وارد github.com شو و یک حساب رایگان بساز یا وارد حساب خودت شو.
2) روی New repository بزن، یک نام مثل TelegramRandomTyper انتخاب کن و Repository را روی Public یا Private بگذار.
3) فایل ZIP را در کامپیوتر Extract کن.
4) وارد پوشه TelegramRandomTyper_Android شو؛ محتویات همین پوشه (از جمله پوشه app و فایل‌های gradle و پوشه .github) را در مخزن GitHub آپلود کن. خود پوشه بیرونی را دوباره داخل مخزن قرار نده.
   نکته: برای دیدن/آپلود پوشه مخفی .github، از گزینه Add file > Upload files استفاده کن یا GitHub Desktop را به کار ببر.
5) پس از آپلود، در مخزن GitHub به تب Actions برو.
6) گردش کار Build Android APK را انتخاب کن و روی Run workflow بزن (اگر با push خودکار اجرا نشده باشد).
7) وقتی اجرا سبز و تمام شد، همان صفحه پایین بخش Artifacts، فایل TelegramRandomTyper-debug-apk را دانلود کن.
8) ZIP دانلودشده را باز کن؛ فایل app-debug.apk داخل آن است. آن را به گوشی منتقل و نصب کن. ممکن است اندروید اجازه نصب از این منبع را بخواهد؛ فقط اگر خودت فایل را از مخزن خودت ساخته‌ای، اجازه بده.

مهم:
- Android Studio روی کامپیوتر لازم نیست.
- برای GitHub و دانلود وابستگی‌ها اینترنت لازم است.
- این روش APK امضاشده برای انتشار در فروشگاه نمی‌سازد؛ خروجی Debug برای نصب و آزمایش شخصی است.
- ساخت ابری هنوز اجرا نشده است؛ APK فقط بعد از انجام مراحل بالا ساخته می‌شود.
